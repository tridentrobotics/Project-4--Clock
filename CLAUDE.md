# Project guidance

## Keep INSTRUCTIONS.md up to date

[INSTRUCTIONS.md](INSTRUCTIONS.md) documents how to build, run, deploy, and extend this project. Whenever you make a change to this repository, check whether it affects that file and update it in the same change. This includes:

- Files or folders added, removed, or renamed (update the project layout tree)
- Changes to robot behavior: controller bindings, autonomous routines, subsystems, commands
- Changes to `build.gradle`, `vendordeps/`, `.wpilib/wpilib_preferences.json`, the WPILib/GradleRIO version, Java version, or team number
- New or changed build, simulate, deploy, or test steps
- New troubleshooting knowledge

If a change doesn't affect the instructions, leave the file alone. Mention in your reply whether you updated it.
